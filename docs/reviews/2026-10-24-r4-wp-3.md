## Result

Implemented the pure strategy/benchmark ledger engine for both approved cost profiles. The public
entry point uses the fixed production capital; the only smaller-capital entry point is private and
compiled under `cfg(test)`. The engine consumes the supplied validated schedule, signal snapshots,
and checked evaluation price rows. It does not create a calendar or signals and has no provider,
file, database, HTTP, job, or process I/O.

The implementation uses the closed WP-2 record and ledger constructors, checked integer money/share
arithmetic, a bounded binary search for cost-inclusive whole-share quantity, and the existing exact
performance and benchmark-difference helpers. It returns both strategy/benchmark pairs together or
returns a typed error.
