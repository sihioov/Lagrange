# Lagrange Station 전체 Koyfin형 UI/UX 적용 계획

기준 명세: `docs/superpowers/specs/2026-09-02-lagrange-koyfin-ui-system.md`
작성일: 2026-09-02
상태: 실행 중

## 목표

Stock Beta에서 검증한 Koyfin형 터미널 셸과 시각 언어를 모든 인증 제품에 공통 적용한다. 제품별
데이터 계약과 작업 흐름은 유지하고, 메뉴 이동 시 레거시 셸로 돌아가는 구조를 제거한다.

## 작업 순서

1. 모든 인증 라우트, 공통 셸, 전역 프리미티브와 회귀 테스트를 목록화한다.
2. `RouteAwareShell`이 모든 인증 경로에서 하나의 터미널 셸을 렌더링하도록 통합한다.
3. 현재 경로 라벨, 역할, 비공개 상태, 언어, 로그아웃과 Stock Beta 유틸리티 슬롯을 보존한다.
4. 공통 셸 범위에서 RoutePage, 패널, 표, 폼, 액션, 상태 화면의 토큰·밀도·반경을 통일한다.
5. Dashboard부터 Live까지 실제 브라우저로 이동하며 잔여 레거시 스타일과 반응형 결함을 수정한다.
6. 셸·역할·접근성 단위 테스트, 타입 검사, 린트, 빌드와 전체 E2E를 실행한다.
7. 데모 서버를 최신 빌드로 재시작하고 Funnel 페이지·번들·메뉴 이동을 검증한다.

## 금지 사항

- 백엔드/API/DTO/인증/데이터 파이프라인 변경
- 가짜 시장 데이터나 작동하지 않는 제어 추가
- 제품별 중복 셸, CSS 숨김 셸, 중복 main/nav
- 권한·fail-closed·provenance·서버 순서 회귀
- 검증 전 완료 또는 외부 확인 가능 주장
